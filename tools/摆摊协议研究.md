# 摆摊 / 上架 协议研究

> 依据：`tools/hotfix_ilspy/hotfix.dll.bytes.decompiled.cs` + 当前 `cg37_Data/assets/hotfixdata/hotfix.dll.bytes`（ildump 验证 StallManager 方法一致）
> 更新：2026-08-09 补充「寻找摊位」纠正（此前误判为 `SendActivityXY("瞬间移动")`，正确是 `SendStallMessage(uid, "寻找摊位")`）

## 1. 协议总览

| 协议 | 值 | 消息体 | 用途 |
|---|---|---|---|
| `LSSPROTO_STREET_FUNC` | **1013** | `Proto_CS_Street` / `Proto_SC_Street` | 地面摆摊：状态、寻找、上架、下架、改价、购买、日志 |
| `LSSPROTO_AUCTIONHOUSE_FUNC` | **3001** | `Proto_CS_Auction` / `Proto_SC_Auction` | 摆摊市场：浏览/搜索/购买 |
| `LSSPROTO_TRADE_BANK` | **4023** | `Proto_CS_TradeBank` / `Proto_SC_TradeBank` | 交易所（离线交易）：上架/重新上架/下架/购买/搜索 |
| `LSSPROTO_OFFLINE_TRADE` | — | `Proto_CS_OfflineTrade` / `Proto_SC_OfflineTrade` | 出售记录/订单管理 |
| `LSSPROTO_ACTIVITY_FUNC` | — | `Proto_CS_Activity` | 通用地图瞬移（大地图点目标位置，`SendActivityXY("瞬间移动")`），**与摆摊无关** |

## 2. 摊位状态（有没有摊位 / 当前售卖多少）

**方法：`StallManager.OpenStall(uid)`** → 协议 1013

```csharp
Proto_CS_Street {
  1: string Type = "摊位状态";
 99: string KUid = uid;
}
```

**响应 `Proto_SC_Street`**：

```csharp
Proto_SC_Street {
   1: string Type;
   2: int    Status;        // 摊位状态标记
   3: Proto_commodityInfoArr Info;   // 摊位数据
   4: repeated Proto_LogInfo Loginfo; // 日志
   6: int    Time;          // 剩余摆摊时间
   7: string Id;
   8: int    Pric;
   9: string Name;          // 摊位名
  10: string Owner;         // 摊位主人
  11: int    Page;
  12: int    Pages;
  13: repeated Proto_SearchStreetInfo SearchList; // 搜索结果
  99: string KUid;
}
```

**判定有无摊位 / 售卖数量**：
- `Info`（`Proto_commodityInfoArr`）为空 → 无摊位或没有商品
- `Info.List`（`repeated Proto_CommodityInfo`）的 `Count` = 当前售卖物品数量
- `Info.Id` = 摊位主人 uid；`Info.Name` = 摊位名；`Info.ObjIndex` = 摊位场景实体索引
- `Status` 字段：3 = 未摆摊状态（客户端 `stallStatus == 3` 时按钮显示「我要摆摊」，否则显示「摊位管理」）

`Proto_commodityInfoArr`:
```csharp
Proto_commodityInfoArr {
  1: repeated Proto_CommodityInfo List;
  2: string Id;       // 主人 uid
  3: string Name;     // 摊位名
  4: int    ObjIndex; // 场景摊位实体索引
}
```

`Proto_CommodityInfo`（单个商品）:
```csharp
Proto_CommodityInfo {
  1: string Id;        // 上架时 = 背包格 index 字符串
  2: int    Type;      // 1=道具 2=宠物
  3: Proto_ItemData Item;
  4: Proto_PetInfo   Pet;
  5: int    Pric;      // 单价
  6: int    Status;    // 2=在售（上架标记）
  7: int    PricType;  // 0=金币 1=钻石
  8: int    Wild;
}
```

## 3. 寻找摊位（瞬间飞到摊位旁） ★ 用户指正

**方法：`StallManager.SendStallMessage(m_Uid, "寻找摊位")`** → 协议 1013

```csharp
// 摊位管理界面按钮 case 6：
ShowMessageBox("是否飞到摆摊位置？", "", delegate {
    Manager<StallManager>.Instance.SendStallMessage(m_Uid, "寻找摊位");
});
```

- 客户端只发 `Proto_CS_Street{Type="寻找摊位", KUid=uid}`
- **传送由服务端完成**（服务端收到后直接把该角色传送到自己摊位旁），客户端无需坐标/寻路
- 与「搜索摆摊」不同：这是「传送到**自己**的摊位」

> 注意：此前把 `ActivityManager.SendActivityXY("瞬间移动", MainPlayerUid, X, Y)` 当作"瞬间飞摊位"是**误判**——那是大地图点击目标点位的通用瞬移协议（`Proto_CS_Activity{Type="瞬间移动", ActivityId=19, TargetX, TargetY}`），不是摆摊专用。玩家视角的"寻找摊位"实际就是上面这个 `"寻找摊位"` Type。

## 4. 搜索摊位（搜索物品 / 找别人摊位）

**方法：`StallManager.SearchStall(searchMsg, uid)`** → 协议 1013

```csharp
Proto_CS_Street {
  1: string Type = "搜索摆摊";
  7: string Id = searchMsg;   // 商品名/关键词
 99: string KUid = uid;
}
```

**响应**：`Proto_SC_Street{Type="搜索摆摊", SearchList=[Proto_SearchStreetInfo]}`

```csharp
Proto_SearchStreetInfo {
  1: string Cdkey;
  2: string Name;      // 摊位名
  3: int    X;         // 摊位坐标 X
  4: int    Y;         // 摊位坐标 Y
  5: int    Viewed;    // 1=已访问 2=不可达
  6: int    ObjIndex;  // 摊位实体索引
}
```

- 搜索结果含摊位坐标（X/Y），客户端点击结果项用 `PlayerEntity.MoveTo(X, Y)` 寻路走过去（`Com_StallSearchItem.OnClickButton`），或用 `EntityContainer.TryGetStall(ObjIndex)` 判断摊位实体是否存在（不存在则灰显"目标摊位已收摊/请在摊位附近查看"）

## 5. 上架物品（地面摆摊）

**方法：构造 `Proto_CS_Street{Type="上架摊位", List=[Proto_CommodityInfo]}`** → 协议 1013

```csharp
Proto_CS_Street {
  1: string Type = "上架摊位";
  3: Proto_commodityInfoArr List;  // 新上架的商品列表
  7: string Id = 摊位名;           // 新建摊位时
 99: string KUid = m_Uid;
}
// 每个商品：
Proto_CommodityInfo {
  1: string Id = 背包格Index.ToString();  // 道具：背包格 index；宠物：data.Index+1
  2: int    Type = 1(道具)/2(宠物);
  5: int    Pric = 单价;                    // 不能 <10
  6: int    Status = 2;                    // 在售
  7: int    PricType = 0(金币)/1(钻石);
}
```

- 商品价格下限：`价格不能小于10`
- 货币选择：UI toggle `shelfTipCurrencyType`，0=魔币/金币，1=钻石（与 `PROTO_CURRENCY_GOLD=0`/`CRYSTAL=1` 一致）
- 上架后如果改了摊位名，额外发 `SendStallMessage(m_Uid, "摊位名修改", name)`
- 修改商品：`Proto_CS_Street{Type="修改商品", List={List:[改价商品]}}`（改 Pric/PricType）

### 上架其它操作（摊位管理按钮）

| Type | 说明 |
|---|---|
| `"我要摆摊"` | 未摆摊时开始摆摊（stallStatus==3） |
| `"摊位管理"` | 管理已开摊位 |
| `"增加时间"` | 延长摆摊时间 |
| `"收起摊位"` | 收摊 |
| `"摊位形象"` | 设置摊位外观 |
| `"摊位名修改"` | 改摊位名（`name` 参数） |
| `"寻找摊位"` | **传送到自己摊位** |
| `"摊位日志"` | 本摊销售日志（`Proto_SC_Street{Loginfo, Page, Pages}`） |
| `"上架摊位"` | 上架商品列表 |
| `"修改商品"` | 改价/改货币 |
| `"一键领取"` | 领取摊销售收入（`GetAllStallLog(uid)`） |

## 6. 上架物品（交易所 / 离线交易）★ 对应可上架表单

**方法：`TradeManager.SendExchangeSellMsg`** → 协议 4023 (`LSSPROTO_TRADE_BANK`)

```csharp
SendExchangeSellMsg(string type, string uid, int num, int price, int curr, int itemIndex = -1, int petIndex = -1)
Proto_CS_TradeBank {
  1:  string Type = "上架道具";   // 或 "上架宠物"
  16: int    Count = num;         // 数量
  14: int    Price = price;       // 单价
  15: int    Tcost = curr;        // 货币：0=金币 1=钻石 (PROTO_CURRENCY)
  12: int    ItemGrid = itemIndex; // 道具背包格（道具上架）
  13: int    PetGrid = petIndex;   // 宠物格（宠物上架，道具为 -1）
  99: string KUid = uid;
}
```

**重新上架/下架：`SendExchangeReSell`**
```csharp
SendExchangeReSell(string type, string uid, long orderId, int price, int curr)
Proto_CS_TradeBank {
  1:  string Type = "重新上架";   // num>0 时
  14: int Price = price;
  15: int Tcost = price;   // 注意：原版把 Tcost 写成 price（可能是原版 bug）
  10: long Orderid = orderId;
  99: string KUid = uid;
}
// num<=0 → Type="下架商品", Price=-1, Tcost=-1
```

**浏览商品列表**：
```csharp
SendExchangeItemMsg("道具详情", mainType, subType, uid, page, sort)
SendExchangePetMsg("宠物详情", petMainType, petSubType, uid, page, sort)
SendExchangeSearch("道具搜索"/"宠物搜索", uid, page, itemId, petId, sort)
```

**购买**：`SendExchangeBuyMsg("购买商品", uid, orderId, num, price)` → `{Type, Orderid=id, BuyNum=num, Price, KUid}`

## 9. 货币枚举（PROTO_CURRENCY）

| 值 | 枚举 | 中文 |
|---|---|---|
| 0 | `PROTO_CURRENCY_GOLD` | 金币（魔币） |
| 1 | `PROTO_CURRENCY_CRYSTAL` | 钻石 |
| 2 | `PROTO_CURRENCY_BIND_CRYSTAL` | 绑定钻石 |
| 3 | `PROTO_CURRENCY_CRYSTAL_ALL` | 钻石（全部） |
| 4 | `PROTO_CURRENCY_CARD` | 点卡 |
| 5 | `PROTO_CURRENCY_FAME` | 声望 |
| 6 | `PROTO_CURRENCY_COINS` | 金币（购买时） |

> 上架/购买 `Tcost` / `PricType` 用 0=金币 1=钻石；购买判断用 `priceType != 0 → CRYSTAL，==0 → COINS`。
