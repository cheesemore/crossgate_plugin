# 魔力宝贝 出手速度（血少先动/魔少先动）公式全解（终极版）

> **整合来源**：魔力百科（華姬）、17173魔力宝贝专区、新浪游戏魔力专区、NGA玩家社区、BlueCG台服论坛  
> **适用范围**：官服/私服通用框架，部分私服参数可能微调  
> **核心原则**：出手速度 ≠ 纯看敏捷，而是 敏捷 + 血魔损失比 + 幸运值 + 技能AS + 指令AS + 二动修正 + 乱敏随机 的综合结果

---

## 一、核心概念：为什么"血少/魔少"会先动？

魔力宝贝的出手顺序并非简单地比较敏捷值。系统会根据一个**综合出手速度值**来决定所有单位（人物+宠物）的行动顺序。

**关键机制**：血量/魔量的**损失比例**会作为乘数放大敏捷值，损失越多，等效敏捷越高，越容易先出手。

这就是玩家常说的"血少先动"和"魔少先动"现象的本质。

> **注意**：血魔损失只修正**出手顺序**，不会改变面板上显示的敏捷数值。（来源：肆飛《血少先动的顺序》）

## 二、出手速度完整公式（華姬版，权威基准）

### 2.1 公式总览

出手速度的计算分为三层：

```
第一层：确定计算模式（随机选取）
第二层：计算！敏捷（240衰减后的有效敏捷）
第三层：代入对应模式公式，计算最终出手速度值
```

### 2.2 第一层：计算模式随机选取

系统首先按以下概率表选取一个数字，决定使用哪种公式：

| 场景 | 模式A（正常公式） | 模式B（乱敏） |
|------|:---:|:---:|
| **PK** | 90%（选0或1） | 10%（选4） |
| **非PK** | 90%（选0或1） | 10%（选2） |

具体数字对应关系（**1动选取数字**）：

| 选取数字 | 概率 | 对应公式 |
|:---:|:---:|------|
| 0 | 45% | 正常公式（敏捷/2系数） |
| 1 | 45% | 正常公式（敏捷/2系数） |
| 2 | PK无 / 非PK 10% | 随机501~1000 |
| 4 | PK 10% / 非PK无 | 随机501~1000 |
| 5 | — | 随机0~500 |
| 5+ | — | 正常公式（敏捷/1系数） |

> **2动选取数字 = 1动选取数字 + 1**  
> 例如1动选0→2动按1算；1动选1→2动按2算。

### 2.3 第二层：！敏捷（有效敏捷）计算

敏捷在参与出手速度计算前，先经过**240衰减**：

```
！敏捷 = 面板敏捷 + 舞技加成百分比 × 面板敏捷    （先算舞技加成）

IF ！敏捷 > 241:
    ！敏捷 = 241 + (！敏捷 - 241) × 0.3
ELSE:
    ！敏捷 = ！敏捷（原值）
```

**示例**：
- 面板敏捷300，无舞技 → ！敏捷 = 241 + (300-241)×0.3 = 241 + 17.7 = **258**
- 面板敏捷200，无舞技 → ！敏捷 = **200**（无衰减）
- 面板敏捷200，舞技加30% → 有效 = 260 → ！敏捷 = 241 + (260-241)×0.3 = **246**

### 2.4 第三层：各模式公式

#### 模式 0-1（正常公式，90%概率）

```
出手速度 = (！敏捷/2 - 50 + 50 + AS + 幸运值×5) × [2 - (当前HP+当前MP)/(HP上限+MP上限)] + 二动修正 + 戒骄戒躁修正

简化：
出手速度 = (！敏捷/2 + AS + 幸运值×5) × [2 - (当前HP+当前MP)/(HP上限+MP上限)] + 二动修正 + 戒骄戒躁修正
```

> **注意**：此模式敏捷取**一半**（！敏捷/2），是正常情况下的主要公式。

#### 模式 2-4（乱敏，PK 10% / 非PK 10%）

```
出手速度 = 随机(501, 1000)    # 完全随机，与敏捷无关
```

> 这就是所谓的"乱敏"——完全打乱正常顺序，任何人都可能先动。

#### 模式 5（罕见，公式中出现但概率极低）

```
出手速度 = 随机(0, 500)
```

#### 模式 5+（正常公式的敏捷满系数版本）

```
出手速度 = (！敏捷/1 + 0 + 50 + AS + 幸运值×5) × [2 - (当前HP+当前MP)/(HP上限+MP上限)] + 二动修正 + 戒骄戒躁修正

简化：
出手速度 = (！敏捷 + 50 + AS + 幸运值×5) × [2 - (当前HP+当前MP)/(HP上限+MP上限)] + 二动修正 + 戒骄戒躁修正
```

> 此模式敏捷取**满值**（！敏捷/1），比模式0-1多了约一倍的敏捷贡献。

## 三、血魔修正系数详解（"血少先动"的核心）

### 3.1 血魔修正公式

公式中的关键乘数部分：

```
血魔修正 = 2 - (当前HP + 当前MP) / (HP上限 + MP上限)
```

等价于：

```
血魔修正 = 1 + (已损失HP / HP上限) + (已损失MP / MP上限)
         = 1 + 失血百分比 + 损魔百分比
```

### 3.2 修正值范围

| 状态 | 当前HP/MP | 血魔修正 | 效果 |
|------|----------|:-------:|------|
| 满血满魔 | HP=上限, MP=上限 | **1.0** | 无加成 |
| 半血半魔 | 各损失50% | **2.0** | 等效敏捷翻倍 |
| 10%血10%魔 | 各损失90% | **2.8** | 等效敏捷×2.8 |
| 1血1魔 | 几乎全损 | **≈3.0** | 接近3倍敏捷 |
| 满血空魔 | HP满, MP=0 | **2.0** | 仅魔的加成 |
| 空血满魔 | HP=0, MP满 | **2.0** | 仅血的加成 |

### 3.3 经典示例（肆飛原文示例改编）

> 角色A：敏捷200，HP上限1000，MP上限500  
> 角色B（敏蜂）：敏捷500，HP上限800，MP上限400

**场景1：双方满血满魔**
- A的血魔修正 = 2 - (1000+500)/(1000+500) = **1.0**
- B的血魔修正 = 2 - (800+400)/(800+400) = **1.0**
- 模式0-1下（简化）：A = 200/2 × 1.0 = **100**；B = 500/2 × 1.0 = **250**
- **B先动**（敏蜂快）

**场景2：A剩100血50魔，B满血满魔**
- A的血魔修正 = 2 - (100+50)/(1000+500) = 2 - 0.1 = **1.9**
- B的血魔修正 = **1.0**
- 模式0-1下：A = 200/2 × 1.9 = **190**；B = 500/2 × 1.0 = **250**
- 仍然是**B先动**

**场景3：A剩10血5魔（≈1血1魔），B满血满魔**
- A的血魔修正 = 2 - (10+5)/(1000+500) = 2 - 0.01 = **1.99**
- A = 200/2 × 1.99 = **199**；B = 500/2 × 1.0 = **250**
- 仍然**B先动**

> **关键结论**：血少先动并不是无限制的。敏捷差距过大时，即使血魔损失到极限也无法反超。但在敏捷差距不大（如30%以内）时，血魔损失的加成足以逆转出手顺序。

### 3.4 实战意义

- **法师/传教**：练级时魔消耗很快，魔少后反而比宠物先动（宠物满血满魔）
- **PK战术**：故意防御挨打降血，下一回合可获得先手优势
- **合击配合**：利用戒骄戒躁降低速度，让二动不被打断

## 四、240衰减对出手速度的影响

### 4.1 规则

出手速度计算中的敏捷也受240衰减影响（与伤害计算中的攻防240衰减一致）：

```
IF 有效敏捷 > 241:
    实际参与计算的敏捷 = 241 + (有效敏捷 - 241) × 0.3
ELSE:
    实际参与计算的敏捷 = 有效敏捷
```

### 4.2 实战影响

| 面板敏捷 | 衰减后！敏捷 | 衰减比例 | 说明 |
|:-------:|:----------:|:-------:|------|
| 200 | 200 | 0% | 无衰减 |
| 241 | 241 | 0% | 临界值 |
| 300 | 258 | 14% | 超出59点只生效17.7 |
| 400 | 288 | 28% | 超出159点只生效47.7 |
| 500 | 318 | 36% | 收益递减严重 |

> **结论**：敏捷超过241后收益大幅下降。堆敏到300左右是性价比最优区间，超过350后每点收益显著下降。

### 4.3 带240衰减的血少先动修正公式（肆飛修订版）

```
出手速度 = (1 + 失血百分比 + 损魔百分比) × [241 + (面板敏捷 - 241) × 0.3]
```

> 适用于面板敏捷 > 241 的情况。

## 五、幸运值系统

### 5.1 幸运值基础设定

- 人物自带随机幸运值，范围 **1~5**（整数）
- 每隔固定时间刷新一次（疑似每小时）
- 战斗中实际幸运值若 < 1 则取 1，> 5 则取 5
- **敌方（怪物）是否拥有幸运值：未确认**。现有所有资料（華姬、KING等）均围绕玩家角色测试，无来源专门验证怪物方的幸运值行为。公式本身是通用结构，但无法据此断定怪物一定有幸运值。

### 5.2 幸运值概率分布

| 幸运值 | 1 | 2 | 3 | 4 | 5 |
|:-----:|:---:|:---:|:---:|:---:|:---:|
| 概率 | 40% | 30% | 20% | 7% | 3% |

> 来源：華姬《幸运值数值几率（参考）》

### 5.3 幸运值对出手速度的影响

在公式中：**幸运值 × 5** 直接加到速度值上。

**等效敏捷换算**（由KING测试验证）：
- 241敏以内：**1幸运值 = 10敏捷**
- 241敏以上：**1幸运值 ≈ 33.33敏捷**

> 这是因为幸运值×5在公式中乘以血魔修正后，与敏捷/2在同一层级运算。

### 5.4 装备幸运值修正

| 装备 | 幸运值修正 |
|------|:---------:|
| 疾风衣 | +5 |
| 艾斯潘头饰 | +5 |
| 星光波动鞋 | +3 |
| 狂战将军的腕轮 | +2 |
| 订婚戒指（亲手获得） | +1 |
| 结婚戒指（亲手获得） | +1 |
| 不幸的戒指 | -5 |

> **注意**：装备幸运值修正与人物幸运值是**相加**关系，最终受1~5范围限制。

## 六、AS（出手速度加成）系统

### 6.1 指令AS值

不同指令会影响出手速度：

| 指令（1动） | AS值 | 说明 |
|------------|:----:|------|
| 逃跑 | +50 | 大幅提前，且2动也享有 |
| 使用道具 | +50 | 大幅提前，且2动也享有 |
| 换装备 | -50 | 大幅延后，且2动也享有 |
| 普通攻击 | 0 | 无加成 |
| 防御 | 0 | 无加成（但为迅速果断提供前置条件） |
| 精灵变身 | 特殊 | 1动变身强制速度=100000（绝对先手） |

### 6.2 技能AS值（迅速果断）

只有**迅速果断**技能具有AS值：

| 技能等级 | AS值 | 攻击提升 | 速度提升 |
|:-------:|:----:|:-------:|:-------:|
| 1 | 10 | +200% | +110% |
| 2 | 20 | +210% | +120% |
| 3 | 30 | +220% | +130% |
| 4 | 38 | +230% | +140% |
| 5 | 46 | +240% | +150% |
| 6 | 54 | +250% | +160% |
| 7 | 60 | +260% | +170% |
| 8 | 62 | +270% | +180% |
| 9 | 63 | +280% | +190% |
| 10（烈·迅速果断） | 64 | +290% | +200% |

### 6.3 迅速果断的特殊规则

- **牺牲下一回合行动**（2动不能行动）
- 1动普攻 → 2动迅速：**无AS加成**（迅速无出手速度加成）
- 1动防御 → 2动迅速：**有AS加成**
- 1动精灵变身 → 2动迅速：**有AS加成**
- 1动其他（非逃跑/道具/换装/攻击）→ 2动迅速：**有AS加成**

> **关键**：一击必中与戒骄戒躁在出手速度公式中等价。

### 6.4 使用道具（丢血瓶）的出手速度机制

**为什么丢血瓶这一轮会特别快？**

据華姬《出手速度公式（参考）》，1动使用道具时，AS=+50，且该AS加成同时传导至2动。这使得使用道具成为除逃跑外最快的行动方式之一。

#### 6.4.1 公式中的体现

以1动丢血瓶为例，代入公式（模式0-1）：

```
出手速度 = (！敏捷/2 + AS + 幸运值×5) × [2 - (当前HP+当前MP)/(HP上限+MP上限)] + 二动修正 + 戒骄戒躁修正
         = (！敏捷/2 + 50 + 幸运值×5) × 血魔修正 + 0 + 1000
```

对比1动普通攻击（AS=0）：

```
出手速度 = (！敏捷/2 + 0 + 幸运值×5) × 血魔修正 + 0 + 1000
```

**差值 = 50 × 血魔修正**

在满血满魔时（血魔修正=1.0），丢道具比普通攻击快 **50点**；在低血低魔时（血魔修正≈2.0），丢道具比普通攻击快 **100点**。

#### 6.4.2 AS=50的传导规则

根据華姬公式和魔力百科的补充说明：

| 场景 | 1动AS | 2动AS | 来源 |
|------|:-----:|:-----:|------|
| 1动丢道具，2动普攻 | +50 | **+50**（传导） | 華姬公式："若有第2动同样享有该AS加成" |
| 1动丢道具，2动技能 | +50 | **+50**（传导） | 同上 |
| 1动普攻，2动丢道具 | 0 | 0 | 1动普攻AS=0，且道具AS仅在1动使用时传导 |
| 1动防御，2动丢道具 | 0 | 0 | 同上 |

> **魔力百科战术建议**：「1動使用道具2動普通攻擊，利用1動使用道具整體提速，提高一動二動速度，這樣的一定程度上團隊二動也有機會保證不被敵人打斷。」

#### 6.4.3 丢血瓶对后续回合的连锁影响

丢血瓶不仅当回合AS=50带来先手优势，还会通过**改变HP值**影响后续回合的血魔修正：

**回合N**：丢血瓶 → HP回复 → AS=+50 → 当回合先手
**回合N+1**：HP已增加 → 血魔修正降低 → 速度优势减少（回到接近正常水平）

反过来，**失血状态**下的丢血瓶更有价值：
- 失血越多 → 血魔修正越高 → AS=50的加成被放大
- 这就是为什么残血时丢血瓶感觉"特别快"——不仅有AS=50，还有高血魔修正的倍率放大

#### 6.4.4 与其他指令的对比

| 指令 | AS值 | 1动速度定位 | 2动是否传导 |
|------|:----:|:---------:|:---------:|
| 精灵变身 | 100000 | 绝对先手 | 不适用（变身后不再行动） |
| 逃跑 | +50 | 极快 | ✅ 传导 |
| **使用道具（含丢血瓶）** | **+50** | **极快** | **✅ 传导** |
| 防御 | 0 | 正常 | ❌ 不传导 |
| 普通攻击 | 0 | 正常 | ❌ 不传导 |
| 换装备 | -50 | 极慢 | ✅ 传导 |
| 戒骄戒躁 | 修正=0 | 极慢 | 修正=0 |

> **结论**：丢血瓶（使用道具）是仅次于逃跑和精灵变身的提速手段，且是**唯一既能提速又能回复**的行动。

## 七、二动修正与戒骄戒躁修正

### 7.1 二动修正

| 行动状态 | 二动修正值 |
|---------|:---------:|
| 1动 | **0** |
| 2动 | **-600** |

> 2动天然比1动慢600点速度，这就是为什么"二动"角色通常后行动。

### 7.2 二动超速修正

当2动的敏捷超过1动时：
```
2动最终出手速度 = 1动最终出手速度 - 随机(50, 60)
```
> 防止2动通过高敏捷完全超越1动。

### 7.3 戒骄戒躁修正

| 使用情况 | 1动修正 | 2动修正 |
|---------|:------:|:------:|
| 1动使用戒骄戒躁 | **0** | **0** |
| 仅2动使用戒骄戒躁 | 1000 | **0** |
| 不使用 | **1000** | **1000** |

> **战术用途**：1动使用戒骄戒躁 → 1动和2动速度都大幅降低 → 团队2动更不容易被打断合击。

## 九、伪代码完整实现

```python
import random

def calc_action_speed(
    panel_agility,       # 面板敏捷
    current_hp,          # 当前HP
    current_mp,          # 当前MP
    max_hp,              # HP上限
    max_mp,              # MP上限
    luck_value,          # 幸运值(1-5)
    as_value=0,          # AS加成(指令/技能)
    is_second_action=False,   # 是否2动
    use_jiejiao=False,   # 是否使用戒骄戒躁/一击必中
    is_pk=True,          # 是否PK
    dance_bonus=0.0,     # 舞技加成百分比(如0.3表示30%)
    is_transform=False,  # 是否精灵变身
    is_fleeing=False,    # 是否逃跑
    first_action_speed=0 # 1动的最终出手速度(用于2动超速修正)
):
    """
    计算出手速度值
    返回值越大越先行动
    """
    
    # === 特殊情况 ===
    if is_transform:
        return 100000  # 精灵变身绝对先手
    
    if is_fleeing and is_pk:
        return 100000  # 逃跑绝对先手
    
    # === 第一层：确定计算模式 ===
    if is_pk:
        mode_roll = random.random()
        if mode_roll < 0.9:
            num = random.choice([0, 1])  # 正常公式
        else:
            num = 4  # 乱敏
    else:
        mode_roll = random.random()
        if mode_roll < 0.9:
            num = random.choice([0, 1])
        else:
            num = 2  # 非PK乱敏
    
    # 2动的数字 = 1动数字 + 1
    if is_second_action:
        num += 1
    
    # === 乱敏模式 ===
    if num in [2, 3, 4]:
        return random.randint(501, 1000)
    if num == 5:
        return random.randint(0, 500)
```

## 十二、常见误区澄清

### 误区1："血少就一定先动"
**错误**。血魔损失只是修正系数（最高约3倍），如果敏捷差距过大（如200 vs 500），即使1血1魔也无法反超满血满魔的高敏对手。

### 误区2："满血满魔时，敏高一定先动"
**基本正确但有例外**。满血满魔时血魔修正=1，此时出手速度主要由敏捷决定。但仍有10%乱敏概率，以及幸运值的微小影响。

### 误区3："水晶属性影响出手顺序"
**基本不影响**。据新浪游戏实验，同敏捷下水晶相克对出手顺序无显著影响。出手顺序主要取决于敏捷+血魔修正。

### 误区4："魔法技能会影响出手速度"
**视情况**。大部分魔法无AS加成。只有迅速果断有AS值。但魔法的施法时间（黄条）与出手速度是不同概念。

### 误区5："血多会拖慢出手"
**不准确**。不是"总血量多"拖慢，而是"当前血量百分比高"意味着修正系数低。1000血损失90%比500血损失40%的修正更高。
