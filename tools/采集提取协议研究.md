## 2. 采集（CollectionManager）

### 2.1 入口

- 快捷键 `HotkeyRecord["Collection"]` → `CollectionManager.Open(uid)`
- 物品来源面板 `GoToSource(resourceId)`：`ItemResourceConfig.SourceId == 3` → `CollectionManager.Open(uid)`
- `Open(uid)`：角色等级 < `TbAreaBaseConfig.OpenLevel` → Tip"X级开启采集功能"；否则 `SendArea("获取数据", uid)`。

### 2.2 请求 `Proto_CS_Area`（`SendArea`，协议 1008）

```csharp
Proto_CS_Area {
  1: string Type;          // 操作类型（见下表）
  2: int    Id;            // 一般 0
  3: int    Num;           // 数量（取出时用）
  4: int    Haveitemindex; // 已采物品索引（取出时用，1 起）；默认 -1
  5: int    Flg;           // 采集类型页：1=伐木 2=采集 3=挖掘（开始采集时 = 页+1）
 99: string KUid;          // 角色 uid
}
```

`CollectionManager.SendArea(string title, string uid, int id=0, int num=0, int haveitemindex=-1, int flg=0)`
→ `NetManager.SendMessage(LSSPROTO_AREA_FUNC, proto)`。

### 2.3 Type 操作值（客户端全部用法）

| Type | 参数 | 说明 |
|---|---|---|
| `"获取数据"` | `(uid)` | 打开面板时请求采集数据 |
| `"开始采集"` | `(uid, 0, 0, -1, page+1)` | 开始采集（page=0伐木/1采集/2挖掘） |
| `"停止采集"` | `(uid)` | 停止当前采集 |
| `"取出物品"` | `(uid, index+1, num)` | **提取物品到背包**（index 是 Itemhave 槽位，从 0 起） |
| `"取出物品到账号仓库"` | `(uid, index+1, num)` | 提取物品到账号仓库 |
| `"删除物品"` | `(uid, index+1)` | 删除已采物品 |
| `"放入需要道具"` | `(uid, 0, 0, bagIndex)` | 放入采集所需道具（bagIndex 为背包格） |

### 2.4 响应 `Proto_SC_AREA`（15 字段）

```csharp
Proto_SC_AREA {
   1: repeated int Level;      // [3] 伐木/采集/挖掘 等级
   2: repeated int Exp;        // [3] 当前经验
   3: repeated int Nextexp;    // [3] 升级所需经验
   4: int Time;                // 剩余采集时间（秒）
   5: int Num;                 // 数量
   6: int Flg;                 // 0=未采集；1=伐木 2=采集 3=挖掘（Flg-1==当前页）
   7: repeated Proto_ItemData Item1;   // 当前地图可采集物（伐木）
   8: repeated Proto_ItemData Item2;   // 可采集物（采集）
   9: repeated Proto_ItemData Item3;   // 可采集物（挖掘）
  10: repeated Proto_ItemData Itemhave;// 已采集到的物品（提取来源）
  11: Proto_ItemData Needitem;         // 采集所需道具
  12: string Place;             // 地图名
  13: int Cardtime;             // 卡时？
  14: string Type;              // "获取数据"/"更新数据"/"上线更新"
  99: string KUid;              // 角色 uid
}
```

- 面板 `OnClickMenus(index)` 用 `Item1/Item2/Item3`（index 0/1/2）展示可采集物；`val.Count==0` 时显示"附近没有东西可以采集"（`m_Obj_Empty`）。
- 面板 `OnShow` → `OnChangedSelectItem(0)` 用 `CollectionManager.ItemConfigs`（由 `CollectionConfig` 按 `Level` 分组）下拉展示采集配置。
- 服务端推送 `"上线更新"` / `"更新数据"` 时更新本地 `AreaInfos` 并派发 `OnEvent`（面板 `OnEvent` 监听 `"更新数据"`/`"获取数据"` 刷新）。

### 2.5 采集配置 `CollectionConfig`（BeanBase，__ID__=1271259344）

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | int | 配置 id |
| Type | int | 采集类型（1伐木/2采集/3挖掘） |
| Name | string | 名称 |
| ItemId | int | 对应物品 id（TbItemConfig） |
| Level | int | 等级 |
| Coordinate | string | 坐标文本 |
| Floor / X / Y | int | 地图楼层与坐标（`OnClickGoto` 用 `GeneralPointMoveTo` 寻路） |
| NeedInfo | string | 所需道具说明 |
| Describe | string | 描述 |

### 2.6 采集时间购买

`RoleManager.SendCurrencyExchange(m_Uid, "获取信息", PROTO_CURRENCY.PROTO_CURRENCY_AREA_TIME(=21), 0)`
→ `LSSPROTO_CURRENCY_EXCHANGE_FUNC`。

## 3. 提取 / 仓库（Bank）

### 3.1 个人/账号仓库

`RoleManager.SendBankMessage(BANK_TYPE banktype, string uid, string type, int index=0, int num=0, List<int> indexList=null)`

```csharp
Proto_CS_Bank {
  1: int Func;                 // 通常 0
  2: string Type;              // 操作类型
  3: int Num;                  // 数量
  4: int Index;                // 槽位
  5: repeated int IndexList;   // 批量槽位列表
 99: string KUid;
}
```

- `banktype`：`BANK_TYPE.PERSONAL_BANK` → `LSSPROTO_BANK_FUNC`(2002)；`BANK_TYPE.ACCOUNT_BANK` → `LSSPROTO_ACCOUNT_BANK_FUNC`(2003)。
- 战斗中禁止 `"存道具"` / `"存宠物"`（客户端 Tip 拦截）。

### 3.2 Type 操作值

| Type | 参数 | 说明 |
|---|---|---|
| `"存道具"` | `(indexList)` | 存入道具（批量槽位） |
| `"取道具"` | `(indexList)` 或 `(index, num)` | 取出道具；账号仓库多物品走 `ShowSelectNum` 选数量后再发 |
| `"存宠物"` | `(index)` | 存宠物 |
| `"取宠物"` | `(index)` | 取宠物 |
| `"整理仓库"` | 无 | 整理排序 |

### 3.3 账号仓库特殊限制

- `PROTO_ITEM_FLAG_LOGOUT_PASS`（下线保护）与 `PROTO_ITEM_FLAG_DICE_PASS`（骰子保护）物品不能存账号仓库。
- 账号仓库个别道具（Type==60）个人仓库不显示。

## 4. 备注

- 采集面板入口还出现在侧栏（`Manager<CollectionManager>.Instance.Open`，336856 行附近为另一入口）。
- `IsPutInBag`（`CollectionManager` 与 `MakeManager` 各有一份）控制采集/制作产出是否入背包（true）或存账号仓库（false）。
- 任务系统 `MissionCondition.RegisterFunction("collection", ...)` 读取 `AreaInfos[uid].Level[index]` 作为任务条件，可用于判断采集技能等级。
- 自动采集思路（若后续实现 DLL）：
  1. 反射 `CollectionManager.Instance`，调 `SendArea("开始采集", uid, 0, 0, -1, page)` 开始；
  2. 监听 `EventCenter`/`CollectionManager.OnEvent` 的 `Proto_SC_AREA`（Type=更新数据）判断 `Flg` 与 `Itemhave`；
  3. 提取：`SendArea("取出物品", uid, i+1, num)` 逐个取出 `Itemhave` 到背包；
  4. 需道具时 `SendArea("放入需要道具", uid, 0, 0, bagIndex)`。
