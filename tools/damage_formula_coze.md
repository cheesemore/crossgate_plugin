## 一、物理伤害公式

### 1.1 核心计算流程

**自然语言描述**：  
物理伤害计算分为三步：
1. 将面板攻防通过「240衰减」转换为实际攻防
2. 用实际攻防计算中值基础伤害
3. 叠加属性/种族/武器/技能等多层修正得到最终伤害

**数学公式**：

```
实际攻击 = f(ATK)
实际防御 = f(DEF)
中值伤害 = 3 × 实际攻击² / (实际攻击 + 3 × 实际防御)
基础伤害 = 中值伤害 × 属性种族修正 × 武器修正 × 浮动系数
必杀追加 = 防御方面板防御 × 攻击方等级 / (防御方等级 × 2)
最终伤害 = (基础伤害 + 必杀追加) × 技能倍率 × 其他修正
```

**伪代码**：

```python
def calc_physical_damage(atk, def_, atk_lv, def_lv, def_panel, 
                        element_bonus, race_bonus, weapon_bonus=1.15,
                        skill_bonus=1.0, is_critical=False,
                        float_range=(0.9, 1.1)):
    """
    计算物理伤害
    
    参数:
        atk: 攻击方面板攻击（含技能加成后）
        def_: 防御方面板防御（含技能加成后）
        atk_lv: 攻击方等级
        def_lv: 防御方等级
        def_panel: 防御方原始面板防御（用于必杀计算，不含技能）
        element_bonus: 属性修正（如1.2表示+20%）
        race_bonus: 种族修正（如1.2表示+20%）
        weapon_bonus: 武器修正（默认1.15，格斗空手也是1.15）
        skill_bonus: 技能倍率（如乾坤1.7、诸刃1.3等）
        is_critical: 是否必杀
        float_range: 浮动系数范围
    
    返回: 最终伤害值
    """
    # Step 1: 240衰减
    threshold = 241  # 大部分服务器241，部分台服250
    actual_atk = atk if atk <= threshold else int((atk - threshold) * 0.3 + threshold)
    actual_def = def_ if def_ <= threshold else int((def_ - threshold) * 0.3 + threshold)
    
    # Step 2: 中值伤害
    if actual_def >= 0:
        base_damage = actual_atk ** 2 / (actual_atk / 3 + actual_def)
    else:  # 防御为负（极少见）
        base_damage = actual_atk ** 2 / (actual_atk / 3) - actual_def
    
    # Step 3: 基础伤害（含浮动）
    import random
    float_coeff = random.uniform(float_range[0], float_range[1])
    race_element_coeff = (100 + element_bonus + race_bonus) / 100
    damage = base_damage * race_element_coeff * weapon_bonus * float_coeff
    damage = int(damage)  # 取整
    
    # 最低伤害保底
    if damage < 1:
        damage = 1
    
    # Step 4: 必杀追加
    if is_critical:
        crit_bonus = int(def_panel * atk_lv / (def_lv * 2))
        damage += crit_bonus
    
    # Step 5: 技能倍率
    final_damage = int(damage * skill_bonus)
    
    return max(1, final_damage)
```

### 1.2 攻防240衰减详解

**规则**：
- 攻击/防御 ≤ 241：全额生效
- 攻击/防御 > 241：超出部分仅30%有效

**公式**：
```
实际值 = 241 + (面板值 - 241) × 0.3   （当面板值 > 241）
实际值 = 面板值                          （当面板值 ≤ 241）
```

**示例**：
- 攻击300 → 241 + (300-241)×0.3 = 241 + 17.7 = **258**（取整）
- 防御400 → 241 + (400-241)×0.3 = 241 + 47.7 = **288**（取整）
- 攻击200 → **200**（无衰减）

**关键点**：
- 是0.3而非1/3，取整方式影响精度
- 部分服务器（如大宇台服）阈值为250而非241
- 攻防升降舞技、技能加成在240衰减**之前**计算

### 1.3 中值伤害公式

**数学表达**：
```
中值伤害 = 3 × ATK² / (ATK + 3 × DEF)
         = ATK / (1/3 + DEF/ATK)
```

**特性**：
- 防御与伤害呈反比例关系（类似y=1/x），防御收益不如攻击显著
- 无必杀、无属性相克、无种族相克、不装备武器时的理论值
- 产生21种波动：90%~110%（以1%为刻度）

**武器波动（额外叠加）**：
| 武器类型 | 波动范围 | 说明 |
|---------|---------|------|
| 空手 | 100% | 无额外波动 |
| 小刀 | 50%~80% | rand(5,8)×0.1 |
| 回力 | 10%~60% | rand(1,6)×0.1 |
| 其他武器 | 无额外波动 | 仅有15%固定加成 |

## 二、魔法伤害公式

### 2.1 核心计算流程

**自然语言描述**：  
魔法伤害计算分为四步：
1. 根据精神值计算精神发挥系数（是否达到发动门槛）
2. 根据魔攻计算魔攻修正系数
3. 叠加属性/种族修正
4. 乘以基础魔法威力得到最终伤害

**数学公式**：

```
精神门槛 = 103 + 魔法等级 × 20
魔攻门槛 = 10 + 30 × (魔法等级 - 1)

精神发挥系数 = min(0.8, 0.8 × 自身精神 / 精神门槛)
魔攻系数 = min(0.4, (自身魔攻 - 魔攻门槛) / 魔法等级 / 10)

基础伤害 = 魔法基础值 × 精神发挥系数 × (1 + 魔攻系数)
最终伤害 = 基础伤害 × 精神比系数 × 属性种族修正 × 浮动系数
```

**伪代码**：

```python
def calc_magic_damage(caster_mnd, target_mnd, caster_matk, magic_lv,
                     caster_is_player=True, magic_type="single",
                     element_bonus=0, race_bonus=0):
    """
    计算魔法伤害
    
    参数:
        caster_mnd: 施法者精神
        target_mnd: 目标精神
        caster_matk: 施法者魔攻
        magic_lv: 魔法等级（1-10）
        caster_is_player: 是否为玩家（宠物/怪物为False）
        magic_type: "single"/"strong"/"super"/"absorb"
        element_bonus: 属性修正百分比（如20表示+20%）
        race_bonus: 种族修正百分比（如20表示+20%）
    
    返回: 最终魔法伤害
    """
    # 基础魔法威力表
    BASE_DAMAGE = {
        "single": [95, 171, 239, 303, 368, 432, 497, 570, 646, 722],
        "strong": [57, 103, 143, 182, 221, 259, 298, 342, 388, 433],
        "super":  [38, 68, 96, 121, 147, 173, 199, 228, 258, 289],
        "absorb": [63, 114, 159, 202, 245, 288, 331, 380, 430, 481]
    }
    
    # 宠物魔法威力约为人物的90%
    PET_RATIO = 0.9 if not caster_is_player else 1.0
    
    base = BASE_DAMAGE[magic_type][magic_lv - 1] * PET_RATIO
    
    # 精神门槛
    mnd_threshold = 103 + magic_lv * 20
    
    # 精神发挥系数（0~0.8）
    coeff_b = min(0.8, 0.8 * caster_mnd / mnd_threshold)
    coeff_b = max(0, coeff_b)
    
    # 魔攻门槛
    matk_threshold = 10 + 30 * (magic_lv - 1)
    
    # 魔攻系数（0~0.4）
    if caster_is_player:
        coeff_c = min(0.4, (caster_matk - matk_threshold) / magic_lv / 10)
    else:  # 宠物
        coeff_c = 0  # 宠物无魔攻加成
    
    coeff_c = max(0, coeff_c)
    
    # 精神比系数
    ratio_a = int(caster_mnd / target_mnd * 100)
    if caster_is_player:
        if ratio_a > 119:   coeff_a = 1.1
        elif ratio_a > 113: coeff_a = 1.0
        elif ratio_a > 105: coeff_a = 0.9
        elif ratio_a > 97:  coeff_a = 0.7
        elif ratio_a > 89:  coeff_a = 0.6
        elif ratio_a > 79:  coeff_a = 0.4
        elif ratio_a > 69:  coeff_a = 0.3
        else:               coeff_a = 0.1
    else:  # 宠物
        if ratio_a > 119:   coeff_a = 1.1
        elif ratio_a > 113: coeff_a = 1.1
        elif ratio_a > 105: coeff_a = 1.05
        elif ratio_a > 97:  coeff_a = 0.95
        elif ratio_a > 89:  coeff_a = 0.9
        elif ratio_a > 79:  coeff_a = 0.7
        elif ratio_a > 69:  coeff_a = 0.6
        else:               coeff_a = 0.4
    
    # 基础伤害计算
    damage_a = base * coeff_a * (coeff_b + coeff_c)
    
    # 属性种族修正
    element_race_coeff = (100 + element_bonus + race_bonus) / 100
    
    # 浮动系数（魔法为95%~105%，共11种）
    import random
    float_coeff = random.choice([0.95 + i * 0.01 for i in range(11)])
    
    # 最终伤害
    final_damage = damage_a * element_race_coeff * float_coeff
    
    return max(1, int(final_damage))
```

## 三、属性克制公式

### 3.1 基础属性克制

**克制关系**：地克水、水克火、火克风、风克地

**普通水晶（双方均为10格）**：
```
属性修正 = 100 + 0.3 × [(我地×敌水 + 我水×敌火 + 我火×敌风 + 我风×敌地) 
                       - (我水×敌地 + 我火×敌水 + 我风×敌火 + 我地×敌风)]
```

**简化理解**：
- 纯X打纯Y（被克）→ 修正70%（-30%）
- 纯X打纯Y（克制）→ 修正130%（+30%）
- 双方同属性或无属性 → 修正100%（0%）
- 一方不带水晶 → 视为全克

**示例**：
- 纯水打纯地（水克地）→ 100 + 0.3×(10×10) = 130%（+30%）
- 纯地打纯水（地被水克）→ 100 + 0.3×(-10×10) = 70%（-30%）
- 水5风5打风5地5 → 100 + 0.3×(5×5) = 107.5%（+7.5%，半克）

### 3.2 特殊水晶（6格，多出2格全克）

**希望/强化/强袭水晶**：总属性6格，多出2格按全克计算

**示例**：
- 水5火5 vs 水6火6：
  ```
  修正 = 100 + 0.3×(5×6 - 6×5 - 2×10) = 100 - 6 = 94%
  ```
  多出2格被克 → -6%

- 纯水 vs 水6火6：
  ```
  修正 = 100 + 0.3×(10×6 - 2×10) = 100 + 12 = 112%
  ```
  克4格 → +12%

### 3.3 魔法属性克制（独立于水晶）

**公式**：
```
魔法属性修正 = 100 + 0.345 × [(魔法地×敌水 + 魔法水×敌火 + 魔法火×敌风 + 魔法风×敌地)
                            - (魔法水×敌地 + 魔法火×敌水 + 魔法风×敌火 + 魔法地×敌风)]
```

**注意**：
- 系数0.345（比水晶的0.3略高）
- 魔法属性与水晶属性独立计算，可叠加
- 吸血魔法的魔法属性 = 施法者水晶属性

## 五、必杀（暴击）公式

### 5.1 必杀伤害计算

**必杀追加伤害**：
```
必杀追加 = [防御方面板防御 × 攻击方等级 / (防御方等级 × 2)]
```

**关键点**：
- 使用**面板防御**（不含技能加成、未经240衰减）
- 必杀追加独立于属性/种族/武器/浮动修正
- 防御为负时，必杀追加-1（反而更低）

**总伤害**：
```
总伤害 = 非必杀伤害 + 必杀追加
```

### 5.2 必杀率计算

**人物必杀修正**：
```
装备斧头：必杀修正 + 技能必杀修正 + 幸运值×4 - 1
未装备斧头：必杀修正 + 技能必杀修正 + 幸运值×1 - 1
```

**宠物必杀修正**：
```
必杀修正 + 技能必杀修正 + 4 - 1
```

**受伤影响**：
- 白伤（未受伤）→ 必杀修正全额生效
- 黄伤 → 必杀修正降低
- 粉伤/红伤 → 必杀修正进一步降低

### 5.3 必杀收益阈值

| 必杀值区间 | 每点暴击率增幅 | 性价比 | 建议 |
|-----------|--------------|-------|------|
| 0~10 | +1.1% | ★★★★★ | 必满10点 |
| 11~20 | +0.7% | ★★★☆☆ | 堆到17最优 |
| 21~30 | +0.2% | ★☆☆☆☆ | 血亏别碰 |

**黄金区间**：17必杀（约29%暴击率）

### 7.2 魔法防御减伤

**魔法防御状态**下，魔法伤害随机减轻为：
- 1点伤害
- 10%伤害
- 20%伤害
- 25%伤害
