## 一、文档 1：档位 → 属性（敌方七维来源）

### 链路

```
查表得极限档(体/力/强/速/魔)
  → 掉档 0~4/项 + 随机 10 档
  → 单项 BP = (档+随机) × [系系数×(等级-1) + 倍率/100]
  → BP × 系数表 → 七维(HP/MP/ATK/DEF/AGI/精神/回复)
```

- **BP→七维**：家养 / 野生 / BOSS **同一套系数**（生命体×8…精神基础 100 等）。
- **野生/BOSS 强在倍率**：倍率全程乘在每级成长上（家养倍率 20 主要只影响 1 级侧写法不同）。
- 实战反向：战斗可见 **血蓝 + 等级 + 名/ID** → 锁倍率（优先 20/50/100…）→ 锁掉档组合 → 推出 ATK/DEF/AGI/精神/回复。

|------|------|
| 敌方名/等级/血蓝 | ✅ 战场可读 |

## 二、文档 2：伤害公式（物理互殴 + 双克制）

> 本项目**只落地物理伤害**；魔法全节保留在 `damage_formula_coze.md` 作资料，不进超级 AI。

### 物理主干

1. **241 衰减**：`实际 = 面板≤241 ? 面板 : 241+(面板-241)×0.3`（取整；部分服 250）
2. **中值**：`3×ATK² / (ATK + 3×DEF)`
3. **叠乘**：`(100 + 属性修正% + 种族修正%) / 100 × 武器(常 1.15) × 浮动 0.9~1.1 × 技能倍率 × …`
4. **必杀追加**（可选精修）：`面板防 × 攻方等级 / (防方等级 × 2)`（面板防、不做 240）

### 属性克制（要算）

- 环：地→水→火→风→地  
- 水晶格公式（双方按「格」计，常见合计 10）：

```
属性修正% = 0.3 × [(我地×敌水 + 我水×敌火 + 我火×敌风 + 我风×敌地)
                 − (我水×敌地 + 我火×敌水 + 我风×敌火 + 我地×敌风)]
```

- 纯克 ≈ +30%，被纯克 ≈ −30%；无属性/同属性 ≈ 0  
- **敌方四维已在配置里**：`ETEARTHAT / ETWATERAT / ETFIREAT / ETWINDAT`（多数合计 100，落地时 **/10 → 格**，再代入上式）  
- **我方**：读装备水晶地水火风格数（待绑战斗/面板）  
- 魔法属性克制（系数 0.345）→ **忽略**（不算魔法）

### 种族克制（要算）

| 关系 | 修正%（文档百分比写法） |
|------|------------------------|
| 全克 | +20 |
| 半克 | +10 |
| 被半克 | −15 |
| 被全克 | −20 |
| 不克 | 0 |

- 全克链：人形→野兽→植物→不死→人形；龙→飞行→昆虫→特殊→金属→龙  
- 半克链：人形→昆虫→植物→特殊→龙→野兽→飞行→不死→金属→人形  
- 邪魔：打其它系 +10%；被其它系打 −20%  
- **敌方种族已在表**：`ETTRIBE` → 0~9（与 monitor 一致：人形/龙/不死/飞行/昆虫/植物/野兽/特殊/金属/邪魔）  
- **我方**：人物固定人形；宠物用自身 `ETTRIBE` / 出场宠配置  
- 注意：文中另有「125%/75%」速查表（约 ±25%），与上表不完全一致 → **先用 ±20%/±10%/−15%，实机校准**

### 其它物理修正（可后加）

武器种类波动、圣盾、防御态、石化、技能倍率、必杀期望等——不阻塞「中值 × 双克制」。

## 三、文档 3：出手速度（谁先动）

### 核心式（正常模式 ~90%）

```
！敏捷 = 241 衰减后的有效敏捷（舞技先加再衰减）
血魔修正 = 2 - (HP+MP)/(MaxHP+MaxMP)     # 满血满魔=1；越残越高
出手速度 = (！敏捷/2 + AS + 幸运×5) × 血魔修正 + 二动修正 + 戒骄戒躁修正
```

- 约 **10% 乱敏**：速度直接随机 501~1000，与敏无关（PK / 非 PK 各约 10%）。
- **二动** 固定约 −600。
- 血魔损失只改**顺序**，不改面板敏。

### 幸运值（已补充标注）

| 对象 | 结论 |
|------|------|
| 人物 | 自带随机幸运 **1~5**（分布约 40/30/20/7/3）；公式内 **幸运×5**；装备幸运可加，战斗内夹到 1~5 |
| 等效 | ≤241 敏：1 幸运 ≈ 10 敏；>241：1 幸运 ≈ 33.3 敏 |
| **敌方（怪物）** | **未确认**。華姬 / KING 等测试均围绕玩家角色，无专门验证怪物幸运；公式结构通用，**不能断定怪物一定有幸运** |

伤害篇另：人物必杀率用幸运（斧头×4 / 非斧×1）；怪物侧同样暂不假设。
