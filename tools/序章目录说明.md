# 序章目录约定

完整更新/补丁规范见仓库根：**[`游戏更新与补丁规范.md`](../游戏更新与补丁规范.md)**。

| 目录 | 用途 |
|------|------|
| `E:\crosscopy\魔力宝贝：序章` | **干净只读源**。跑官方更新 / 对照。**禁止修改、禁止打补丁** |
| `E:\cross\魔力宝贝：序章` | **工作目录**。日常游戏、打补丁、`tools` 产物 |
| `E:\cross\发布plugin\` | 傻瓜补丁 zip 发布目录 |
| `E:\cross抓宠\魔力宝贝：序章` | 抓宠专用实例（若在用） |

**不是** `E:\crossgate_cursor`（另一套 cross.exe / 青春魔力工具链）。

## 启动游戏

```bat
E:\cross\魔力宝贝：序章\cg37.exe
```

## 提取配置（只读 crosscopy → 写入 cross）

```bat
python tools\extract_seqchapter_configs.py
python tools\export_pet_appear_bin.py
```

或预览 GUI 里点「重新导出形象表」（会先提取再导出）。

产物：`tools\_config_extract\`、`pet_appear.*`、`ride_skin.*`、`pet_max_crest.*`
