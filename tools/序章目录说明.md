# 序章目录约定

Agent 入口：**[`AGENTS.md`](../AGENTS.md)** · 模块地图：**[`模块地图.md`](模块地图.md)** · 更新规范：**[`游戏更新与补丁规范.md`](../游戏更新与补丁规范.md)**。

## 目录铁律

| 角色 | 路径（本机示例） | 含义 |
|------|------------------|------|
| **干净版** | `E:\crosscopy\魔力宝贝：序章` | 官方纯净客户端；**只读、永不打补丁**（`SEQCHAPTER_CLEAN`） |
| **打补丁工作区** | `E:\cross\魔力宝贝：序章`（本 git 根，含 `cg37.exe`） | 日常游戏、打补丁、`tools` 产物（`SEQCHAPTER_WORK`） |

建议布局（**目录名**固定，盘符/上级路径可不同；也可用环境变量覆盖）：

| 目录 | 用途 |
|------|------|
| `<盘符>/crosscopy/魔力宝贝：序章` | **干净只读源**。跑官方更新 / 对照。**禁止修改、禁止打补丁** |
| 本仓库根（含 `cg37.exe`） | **工作目录**。日常游戏、打补丁、`tools` 产物 |
| `<游戏目录上级>/发布plugin/` | 傻瓜补丁 zip 发布目录（相对路径 `../发布plugin`；`SEQCHAPTER_RELEASE_DIR`） |
| `<盘符>/cross抓宠/魔力宝贝：序章` | 抓宠专用实例（若在用；`SEQCHAPTER_CATCH`） |

本机常见示例：`E:\cross\…`、`E:\crosscopy\…`，**勿在脚本里写死盘符**。  
过时写法 `E:\cross序章\crossgate_plugin` **已废弃**，勿再用。

**不是** `crossgate_cursor`（另一套 cross.exe / 青春魔力工具链）。

## 启动游戏

在工作目录下启动 `cg37.exe`（或资源管理器打开本仓库根）。

## 提取配置（只读 crosscopy → 写入工作目录）

```bat
python tools\extract_seqchapter_configs.py
python tools\export_pet_appear_bin.py
```

或预览 GUI 里点「重新导出形象表」（会先提取再导出）。

产物：`tools\_config_extract\`、`pet_appear.*`、`ride_skin.*`、`pet_max_crest.*`
