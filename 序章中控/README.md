# 序章中控

独立桌面工具：**多开 / 监视 / 指令**。

- 傻瓜补丁的「启动中控」打的就是本程序（包内「中控\\中控.exe」），不再打包「新序章多开器」。
- **多开**：账号库、一键启动、登录拉多控、召唤，与原多开器同一套 IPC。
- **监视**：读精简桥接 `state.json`（概况、护航停战、脚本运行状态），不扫 `SeqChapterTestUi.log`。
- **指令**：空白，后续再做面板遥控。

启动：`启动序章中控.bat`

监视依赖游戏已注入精简桥接，且该窗口已加载过序章助手（百科打开或「助手自动打开」）。未开助手时仍能看到桥接在线，但没有概况。
